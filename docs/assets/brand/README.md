# Rovo のロゴ

| ファイル | 使う場所 |
|---|---|
| `rovo-logo.svg` | README の先頭など、大きく見せるところ（円の中に胴体・歯車・R のロボ・文字） |
| `rovo-mark.svg` | アイコンの本体（R のロボ。背景なし）。32px 以上 |
| `rovo-mark-small.svg` | 16px 前後のファビコン（帯・陰・光を省き、目を大きくした簡略版） |
| `rovo-lockup-dark.svg` | 暗い背景に置く横長のロゴ（丸いバッジと文字） |
| `rovo-lockup-light.svg` | 明るい背景に置く横長のロゴ（輪郭付きの文字） |

- 表記は「Rovo」（R だけ大文字）。パッケージ名・コマンド・URL は小文字の `rovo` のまま。
- 文字は [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat)（SIL Open Font License 1.1）の ExtraBold を図形（アウトライン）にしたもの。フォントが無い環境でも同じ形に見える。
- 色: 黄 `#ffd54a` → 橙 `#f08c16`、輪郭 `#0b0d16`、レンズ `#2fae98`、背景の紺 `#0a0d18`。
